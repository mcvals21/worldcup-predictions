# موقع توقعات كأس العالم

نسخة أولية بسيطة ومناسبة للهاتف لمسابقة توقعات بين الأصدقاء.

## التشغيل على جهاز الكمبيوتر

1. ثبّت Python 3.11 أو أحدث.
2. افتح Terminal داخل هذا المجلد.
3. نفّذ:

```bash
pip install -r requirements.txt
flask --app app init-db
flask --app app run --host=0.0.0.0 --port=5000
```

## فتحه من الهاتف داخل نفس شبكة الواي فاي

1. شغّل الموقع على الكمبيوتر بالأمر السابق.
2. اعرف رقم IP للكمبيوتر.
   - Windows: افتح CMD واكتب `ipconfig`
   - Mac: افتح Terminal واكتب `ipconfig getifaddr en0`
3. من الهاتف افتح المتصفح واكتب:

```text
http://IP-ADDRESS:5000
```

مثال:

```text
http://192.168.1.20:5000
```

لوحة الإدارة:

```text
http://IP-ADDRESS:5000/admin/admin-2026
```

## روابط مهمة على نفس الجهاز

- الترتيب: http://127.0.0.1:5000/leaderboard
- الإدارة: http://127.0.0.1:5000/admin/admin-2026

بعد تشغيل `init-db` ستظهر روابط المشاركين في الـ Terminal.

## ما الذي تم تحسينه للهاتف؟

- تصميم Responsive للشاشات الصغيرة.
- أزرار كبيرة مناسبة للمس.
- حقول أرقام سهلة للتوقعات.
- الترتيب يظهر كبطاقات بدل جدول على الهاتف.
- توقعات المباراة تظهر كبطاقات على الهاتف.
- لوحة الإدارة أصبحت أسهل من الجوال.

## ملاحظات مهمة

- التوقيت المدخل في لوحة الإدارة هو توقيت السيرفر/الجهاز.
- التوقعات تغلق تلقائيًا عند بداية المباراة.
- توقعات الآخرين لا تظهر إلا بعد إغلاق المباراة.
- النتيجة المعتمدة للأدوار الإقصائية هي بعد الأشواط الإضافية، بدون ركلات الترجيح.
- المضاعفة مسموحة فقط مرة واحدة لكل دور إقصائي لكل مشارك.

## للاستضافة لاحقًا

يمكن رفعه على Render أو Railway أو PythonAnywhere. عند الاستضافة يجب تغيير `SECRET_KEY` و `ADMIN_CODE`.
